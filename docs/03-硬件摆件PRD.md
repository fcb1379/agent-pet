## 2. 产品定位

一个常驻桌面的实体角色终端。它不是独立 AI 音箱，也不是电脑性能仪表盘；它将电脑端已理解的工作情境转化为可感知的表情、灯效和动作，并将用户的实体互动低延迟传回电脑。

## 3. 成功指标

- 新用户从上电到完成绑定的中位时间小于 2 分钟。
- 正常环境下 8 小时工作时段连接可用率不低于 99%；测试时电脑与摆件距离不超过 2 米、无主动射频屏蔽，累计不可用时间按无法传递心跳或事件的时段统计。
- AI 状态开始变化到硬件反馈 P95 小于 1 秒。
- 本地触摸/按键反馈小于 50 ms，传到电脑 P95 小于 300 ms。
- 连续运行 72 小时无死机、内存持续增长或必须人工重启。
- 至少 5 名首次使用的内测用户中，80% 能在完成一次不超过 3 分钟的引导后，不借助日志正确识别“离线、等待确认、工作中、出错”四类状态；每类状态分别统计。

## 4. 用户故事

1. 作为 AI 重度用户，我想远离 AI 窗口时仍知道任务是否需要我。
2. 作为桌面用户，我想触摸摆件获得即时回应，而不是等待网络往返。
3. 作为隐私敏感用户，我想明确知道设备是否连接、采集什么，并能实体清除绑定。
4. 作为开发者，我想在不修改角色业务代码的前提下替换屏幕、灯珠或传感器。
5. 作为设备拥有者，我想升级失败后设备仍可恢复，而不是变砖。

## 5. 功能需求

优先级：P0 为 MVP 必须；P1 为首版增强；P2 为后续探索。

### 5.1 表达输出

| ID | 需求 | 优先级 | 验收 |
|---|---|---|---|
| OUT-01 | 至少表达 AI 待机、思考、工具执行、等待用户、成功、错误，以及设备断连 | P0 | 盲测能区分关键状态，且 AI 状态与设备连接状态使用独立通道或可组合表达 |
| OUT-02 | 动作可按 display/light/motion 通道组合 | P0 | 缺失通道时自动降级且不报致命错误 |
| OUT-03 | 支持优先级、打断、循环、恢复 | P0 | 安全提示可中断普通动作，结束后恢复正确状态 |
| OUT-04 | 用户可调亮度并设置勿扰时段 | P0 | 勿扰模式无突发高亮/声音/大动作 |
| OUT-05 | 使用扬声器播放提示音和角色音效 | P0 | 可独立调节或静音；勿扰模式不播放；不出现明显开关机爆音 |
| OUT-06 | 语音播报 | P0 | 可独立关闭；勿扰模式不播放；播报不得包含未授权的提示词或回复正文 |

MVP 固定使用自适应显示屏、扬声器、RGB 和震动形成多通道表达，并支持屏幕交互；具体屏幕、触控、扬声器和震动执行器规格仍需实机冻结。复杂机械动作不进入 MVP 必需范围。

## 6. 非功能需求

### 6.1 性能和资源

- UI 动画目标帧率按屏幕和功耗验证后确定；降帧不能阻塞 BLE 和输入处理。
- UI 使用逻辑画布、锚点、相对尺寸和安全区域适配不同分辨率；不得把像素坐标和单一宽高写入角色业务逻辑。
- 协议解析、连接、表达和资源更新使用有界队列与静态上限。
- 任何来自电脑的尺寸、索引、时长和动作参数均视为不可信输入。
- Flash/RAM 预算在板级 spike 后形成表格，并预留至少 20% 运行余量；未形成预算前不得承诺复杂动画规格。

### 6.2 功耗与热

- 原型优先 Type-C 5V/2A 供电。开发板已具备 AW32001ECSR 充电管理（最高充电电压 4.5V、最大充电电流 500mA）和 GH1.25 电池接口，但接入电芯前仍须确认支持的电池体系、温度检测、保护、终止策略和原理图连接。
- 明确工作、待机、勿扰、断连和升级五种功耗模式。
- 表面可触区域和芯片温度阈值需结合结构与器件标准验证；过温由固件本地降亮度/停动作并上报。
- 若引入电池，需增加电芯匹配、充放电保护、运输、寿命、认证和电量估算需求。开发板“有充电管理”不等于电池产品方案已完成。

### 6.3 可靠性和安全

- 上电、掉电、棕断、BLE 风暴、资源损坏和执行器堵转不得造成不可恢复状态。
- 机械执行器必须有限位、超时和最大占空保护；电脑端不能关闭这些保护。
- 升级包签名、公钥保护、反回滚策略和调试口量产锁定需在 EVT 前定义。
- 所有日志默认脱敏，设备不存储 AI 内容。

### 6.4 人因和体验

- 设备离用户较近，默认表现应安静、低亮、低频；高频闪烁和突然机械动作禁止作为常态反馈。
- 状态不能只靠颜色区分，需要形态/节奏/表情中的第二编码，兼顾色觉差异。
- 物理静音/勿扰动作应始终可用，并有持续可见反馈。

## 7. 硬件能力抽象

固件向上报告实际能力，不假定每个 SKU 都具备全部器件：

```text
Display: dimensions, pixel formats, fps class, partial update, input capabilities
Light: count, RGB/RGBW, brightness levels
Motion: actuator type, axes, safe ranges, concurrent channels
Input: button/touch/IMU event vocabulary
Audio: speaker/mic availability, permission state, capture indicator and volume class
Storage: resource capacity, maximum object, update slots
Power: source, battery/charging telemetry, sleep classes
Transport: BLE features, negotiated message size, optional UART
```

角色资源包提供 `required` 与 `optional` 能力以及 fallback。这样同一电脑端可以支持“只有灯效的小摆件”和“带屏幕与动作的完整版”。

## 9. SF32LB525 黄山派原型验证清单

以下必须以开发板原理图、SDK 示例和实测确认，当前不把猜测写成产品承诺：

1. 可用 SRAM/PSRAM/Flash 分区及显示帧缓冲后的余量。
2. BLE 版本、MTU、吞吐、连接间隔、安全配对和后台重连表现。
3. 22Pin FPC 配套屏幕扩展板的控制器、分辨率、触摸 IC、刷新率、局刷、DMA 和动画解码能力。
4. CH340N 串口的烧录、日志和恢复流程；确认 Type-C 数据线是否只接 CH340N，以及 MCU 是否另有原生 USB/DFU 路径。
5. 可用 GPIO/PWM/I2C/SPI/ADC 数量与开发板已占用资源。
6. 低功耗、温升和 USB 供电稳定性。
7. 内置 Flash 与 TF 卡的资源分工、热插拔/文件损坏行为、Flash 写入寿命和可行的 A/B 或恢复分区。
8. RTOS、BLE 栈和图形库许可证及量产约束。
9. 看门狗、崩溃信息、唯一设备标识和随机数能力。
10. 马达驱动拓扑、电流与保护，外接马达时对 IMU、地磁、音频、BLE 和供电的干扰。
11. MEMS MIC 接口、采样链路及能否由硬件电源域关闭；NS4150B 的扬声器负载与静音爆音控制。
12. AW32001ECSR 支持的电芯体系、4.5V 配置来源、温度检测和电池保护要求。

## 11. 状态与异常定义

| 场景 | 必须行为 |
|---|---|
| 未绑定 | 低打扰配对提示，不广播用户信息 |
| 正常断连 | 显示离线，保留本地互动，指数退避等待重连 |
| 电脑休眠 | 进入安静模式，可由本地互动短暂唤醒表现 |
| 协议不兼容 | 清楚提示需升级，不循环重启或误执行 |
| 存储不足 | 保留基础内置资源，拒绝新包并上报所需空间 |
| 原型刷写/升级中断 | 可以通过 CH340N 恢复；开放 OTA 后必须回到旧固件或恢复模式 |
| 过温/执行器异常 | 本地停止危险输出，上报告警，需满足恢复条件再启用 |
| 固件崩溃 | 看门狗重启，记录受限崩溃摘要，避免重启风暴 |

## 12. 研发阶段出口标准

### EVT 前原型

- 完成板级验证清单和资源预算。
- BLE 安全绑定、重连、状态同步和互动闭环可演示。
- 连续 72 小时稳定性通过。
- 固件恢复路径已被真实断电测试。

### EVT

- 冻结功能块、接口、供电、安全机制和可制造性方向。
- 完成初版结构、人因、EMC 预扫和热测试。
- 关键器件有供货与替代策略。

### DVT/PVT

需要在量产目标、市场和合规地区明确后补充认证、跌落、寿命、ESD、EMC、包装运输、工装、序列化和产测规范。
